# 05　私人工作台、动态回答、业务来源和固定视图

复验先从 A 的个人首页，再进入与 B 共有的团队。为避免模型随机输出妨碍复验，本轮同时采用两类条件：运行中/停止使用原版 API 与本地延迟响应端；已完成回答由隔离库中的人工业务夹具提供。夹具只决定初始数据；显示、交互、保存、权限、路由均由原版处理。真实模型生成质量仍需有额度时复核。

| <a id="wb-01"></a>WB-01 | 个人或团队初入首页 | 顶栏工作区，下方左侧“新对话/我的视图/基础能力/最近对话”，底部为用户名和区类型；右区显示工作区名、欢迎语、推荐问题及项目/任务/话题计数，底部提问区。个人同样列项目、任务、收件箱、智能体小队、成员与智能体 | 本轮原版实测 [图 02](evidence/02-personal.png) [图 05](evidence/05-team-home.png) |

| <a id="wb-10"></a>WB-10 | 选 fingerprint 已过时的固定视图，再按刷新 | 本轮选择后自动显示“正在刷新…”及保留上次完整结果；相同指纹无须模型并保持当时状态，不同指纹需重新分析。刷新中禁手动刷新；失败保留旧结果和提示；同组件里按 pin/fingerprint 去重，当前 pin 的预算最多两次、间隔至少 30 秒，换 pin 会切换预算 | 自动刷新实测 [图 28](evidence/28-pin.png)；H04；真实重新生成待验证 |
