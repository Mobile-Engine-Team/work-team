# 03　创建、分派、执行、交付与收件箱

从 A 的团队首页进入侧栏“任务”。先让 B 成为成员，再准备 A 的共享 Pi 智能体“复验助手”，将其执行端停用。下列“核对交接清单”“离线分派”和“暂不启动”是三条独立任务。重放时每条只创建一次；系统分配的编号可能跳号，按标题、ID 之间的引用和归属比对。
