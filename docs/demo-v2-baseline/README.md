六章登记 **185 项操作、状态及可达性疑问**，另有 **8 项裁决记录**。证据目录有 40 张原版截图、53 份界面结构及焦点记录，并附服务端业务结果。覆盖表逐条指出哪些只是打开过表单，哪些已观察到提交结果或另一位成员的反馈。

**可先审三处。** 工作区表单的地址可填非法值并点创建；Esc、叉号、遮罩甚至成功后，重开仍保留输入。团队成员 B 可以使用 A 共享的助手，自己的机器目录却看不到 A 的执行端。B 确认离线分派后，业务任务是“进行中”，执行却是“排队中”；B 停止该执行后，任务仍是“进行中”。这些判据分别见 WS-03～12、AG-03～09、RUN-01～06 及 STATE-07。

本轮评审停在冻结原版。截图来自原生窗口内容，服务端运行用冻结二进制。已有用户状态同时保留历史证据和本轮合成数据实测；真实付费生成、SSH、已被 CLI 领取的工作以及少数异常路径仍有证据缺口。用户已确认交付一个可双击的通用 .app，同机换号时隔离私有数据，本地目录布局由实现决定。D-07 两项任务交互变更已批准。旧数据可尝试迁入，成本高时可用新账号重建同等条件。真实模型与外部 SSH 验证暂缓。
