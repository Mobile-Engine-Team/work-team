# 02　把一位成员的执行端和智能体交给团队使用

A 在“基线协作组”是所有者，B 是成员。先注册、组队，再用 A 的隔离桌面资料启用本机执行端。工具目录来自该机器的安装；个人和团队场景必须分别打开表单。以下表格用同名按钮上的文字和所在区域区分入口。
