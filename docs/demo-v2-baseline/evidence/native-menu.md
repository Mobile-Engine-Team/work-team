# macOS 菜单逐项入口

同机 B 实例，由系统辅助功能枚举。归档应用菜单名中的本机账号以 `[profile]` 表示。每个编号对应给定测试条件下的一项可见菜单。名称见[枚举及动态观察](native-menu.json)。菜单启用可能取决于窗口焦点、选区、系统服务及构建；仅枚举到名称的行保留点击结果待测。窗口常驻和冷启动证据见[启动章](../01-启动与工作区.md)和[已有用户章](../06-已有用户与裁决.md)。
