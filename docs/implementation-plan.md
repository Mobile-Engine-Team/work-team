# 第一批迁移实施计划

## 交付顺序

|阶段|实现与评审点|通过条件|
|---|---|---|
|1 盘点与搭架|逐页列出冻版可见动作、输入、权限条件、来源文件和验证方法，标清属于首批还是后续；建立 pnpm workspace、锁定 DSH、产品 profile 与 bundle、开发和停止脚本；准备本机专用 DB/API/上传目录。|从干净的产品资料目录启动 DSH。真实浏览器显示产品壳，受保护请求到达 Host，未登录访问被拒。记录最终采用的树外 Client 构建和 Host 调用方式。|
|2 贯通工作区|先完成真实注册／登录、列出工作区、创建和切换、会话恢复及退出。按当前空间注册导航，沿用 V2 布局。|两个隔离客户端同时在线；新用户见到个人工作区，空团队仍是团队类型。刷新与快速切换后无跨账号、跨空间数据。|
|3 任务和收件箱|接入已有任务模型和表单所需查询、详情、评论、通知操作。先约定跨页导航，再由两个包分别实现。|两位成员以自己的身份操作。B 从真实通知打开 A 对应的评论，刷新后状态持久，另一个空间看不到此任务。功能矩阵覆盖两页的首批动作。|
|4 成员、小队和执行端|实现邀请与接受、Agent 配置、小队及成员角色，接本机执行端管理。执行端可与阶段 3 并行，联调时共享独立实例与清晰的测试账号。|两人一组和至少一个本机 Agent 可操作；服务器认得 daemon，Agent 绑定到正确 runtime。验证一次真实派工及回执，记录实际执行器和模型条件。|
|5 交付与复盘|从干净安装检查包解析及插件开关，做浏览器端全流程与故障复测，补充启动命令、已验证功能矩阵和限制。|按下表逐项记为通过、失败或未验。提交独立产品仓内的实现与验证说明；附两项真实改动的跨包成本。|

工作可按阶段提交。接口名和字段先对照 V2 调用点与服务端定义。遇到 Remote 或打包问题，优先尝试详设中的受保护 Host 路由，继续完成业务验收。若上游差异确实阻塞，记录实际错误、受影响的功能和已尝试的恢复路径，同时完成不受影响的页面。

## 验收场景与证据

|编号|从真实产品入口执行|要核对的结果|
|---|---|---|
|A1|本机启动 API、DSH Host/Client，从新用户注册，退出后用账号密码再次登录。|自动出现唯一的个人空间；会话按选定策略恢复。错误密码有反馈，退出后旧页不能继续读取团队数据。|
|A2|A 点击顶栏「＋」建团队，邀请 B；B 从自己的客户端接受。切换个人／团队空间并刷新。|创建者为 owner，另一账号只在接受后出现。列表、侧栏和成员名单一致；请求时序不会把前一空间数据写回当前页。|
|A3|创建带状态及负责人的任务，筛选、打开详情、修改并评论；用 V2 已支持的提及／订阅规则为 B 产生通知。|服务器持久化的同一 issue 和 comment 可在两个账号读取。按 V2 可见条件检查任务页动作清单，记录未覆盖项。|
|A4|B 在收件箱切换已读／未读、归档／恢复，从同一任务的不同通知定位到指定评论。|任务包定位到事件自身锚点，浏览器刷新和返回正常；缺失目标有用户可见反馈。|
|A5|在成员页登记或选择实际本机 runtime，建立 Agent，在小队页创建小队、设置负责人、添加成员和角色、编辑后重新打开。|绑定及角色修改能从 Multica 回读；个人空间邀请限制、团队操作权限遵循冻版行为。|
|A6|从 UI 启动本产品 daemon，检查在线和绑定；派一个最小本地任务，查看领取、运行及回执，然后停止并重启。|记录 runtime/run 标识的脱敏片段、实际执行条件和页面结果。独立实例重启不产生意外新绑定。若测试用确定性执行器替代模型，分别列出真实服务/daemon 链路和模型验证边界。|
|A7|分别禁用 execution-bridge、移除 ui-inbox 后启动，再恢复默认组合。|前者仍可管理团队，后者去除收件箱入口且其余页面可用。独立安装可解析所有产品包；开启后恢复。|
|A8|断开产品测试 API 再恢复，测试会话过期、越权跨空间、重复点击提交。|错误可见、恢复后数据正确、无重复提交或数据串读。不要在此过程中停止原 V2 服务。|

验证分层记录。包构建、类型／边界检查、契约测试、真实 API、真实浏览器交互、daemon 运行及模型结果分别提供命令和结果。README 给出负责人可以直接操作的本机入口和复验步骤。展示数据使用本次测试生成的数据。验收优先通过产品 UI 操作，数据库或 API 回读只作交叉核对。

## 如何评估 DSH 的收益

保留两项真实需求的实现差异。第一项是任务列表对已有字段的筛选，观察是否只改 ui-tasks。第二项是从收件箱打开指定评论，观察壳导航契约和任务、收件箱两包的联调成本。记录预计与实际改动包、契约变化、返工原因和验证范围。单列首次学习、树外打包和运行时装配的成本。这些数据供迁移后的复盘使用。
