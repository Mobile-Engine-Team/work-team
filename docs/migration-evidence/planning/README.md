# 规划建议与结论草稿回放

从产品目录运行以下命令。先按[桌面重放说明](../README.md)启动本产品的 PostgreSQL、Multica 和资料 A 的 DSH Host。脚本新建两名合成成员、一个团队和一个项目，在独立 Chrome 窗口中登录 A。

```sh
python3 tests/review/planning.py --output .local/replay-planning
```

| 基线 | 操作与核验 |
| --- | --- |
| PL-02、PL-03 | 修改输入后必须重新预览才可生成。申请保留请求键、输入 hash 和 revision。观察等待、领取、取消、迟到回执 409、错误结果和成功历史。 |
| PL-04 | 仅选连线时服务端拒绝。改选任务后重新预览，采纳两项任务中的一项，只写入草案。B 回读一致，正式版本及建议对应的业务任务计数均为 0。用旧 revision 尝试第二项会收到 409。 |
| TC-05 | 从结论编辑器申请、取消、重新生成、插入和保留草稿。重开编辑器可继续修改，B 回读草稿及开放状态，确认版本为 0。 |

测试夹具只登记本机合成 Pi 端，用冻结 Multica 的领取接口和单请求回执写入受控结果。生成内容、失败原因、草案 revision、确认版本均由产品接口或数据库读回。D-08 的真实模型、成本和输出质量保留待验。
