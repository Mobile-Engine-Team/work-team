快速开始

本章节面向第一次上手 Loop 的用户。标准路径是先安装 Loop Desktop，然后在 Desktop 内完成第一次智能体对话。

完成这个快速开始后，你应该能够做到：

下载并打开 Loop Desktop
在 Desktop 内注册或登录，并进入自动创建的工作区
进入“快速上手”频道
创建第一个智能体
在话题里看到智能体完成第一次回复
开始前确认
打开 https://loop.pingkai.cn/download 下载适合当前系统的 Loop Desktop。
安装并打开 Loop Desktop。首次使用时，在 Desktop 内完成注册或登录。

Web 端可以继续作为普通工作区入口使用，但不会创建或执行快速上手教程。未完成快速上手时，如果在浏览器里打开教程频道链接，Loop 会提示你回到 Desktop 继续。

参与本流程的 Desktop 发布版只为 2026 年 8 月 5 日之后注册的账户启用快速上手。更早注册的账户仍会进入普通工作区，不会创建或自动打开“快速上手”频道；符合条件并通过 Desktop 完成注册的新用户还会收到 onboarding 试用积分。

开始使用
第 1 步：打开 Loop Desktop

安装后打开 Loop Desktop，并按界面提示登录。登录成功后，Loop 会进入你的默认工作区。

第 2 步：进入快速上手频道

如果你还没有完成首次智能体对话，Desktop 会自动打开“快速上手”频道。这个频道是真实频道，用于帮助你跑通第一次人机协作。

第 3 步：创建第一个智能体

在快速上手频道中点击“创建智能体”。首次创建会使用推荐默认配置：内置运行时、默认机器和推荐模型。你通常只需要确认智能体名称。

创建成功后，智能体会自动加入快速上手频道，消息流里会出现对应的成员事件。你不需要手动把它添加到频道。

第 4 步：等待示例对话完成

智能体准备好后，Loop 会分阶段演示一次对话：

在快速上手频道发送一条示例需求。
短暂停留，让你看到频道消息。
打开这条消息对应的话题。
在话题里提及刚创建的智能体。
短暂等待后，显示保存好的智能体回复，并附上对应界面语言的 index.html。

第一次示例是一段引导演示：Loop 会保存外观与普通对话一致的消息，但不会要求智能体运行时真正生成结果，因此教程的速度和结果更稳定。保存的回复和游戏会根据当前界面语言提供简体中文、英语或日语版本。

结果会直接在话题中以 HTML 附件形式预览。预置智能体回复会直接结束快速上手；回复出现约一秒后，Loop 会显示完成提示和一次短暂的纸片礼花效果。示例结束后发送的消息会正常交给真实智能体处理；你可以继续追问，也可以去其他频道开始自己的任务。

Web 入口

网页版适合后续查看频道、话题、任务和历史消息。快速上手教程本身只在 Desktop 中执行；Web 不会自动创建快速上手频道，也不会自动发送教程消息。

完成快速上手后，“快速上手”会作为普通频道继续存在，但频道设置入口仍会隐藏，避免误改教程频道名称。
