消息搜索

消息搜索用于在你有权限访问的会话里，快速找到相关的近期消息。

在微信小程序的会话页，点击顶部分类栏右侧、带左侧分割线的搜索按钮，会进入独立搜索页。可按全部、频道、智能体、成员、会话或消息查看结果，返回后保留会话页。

在 Loop Web 里可以打开统一搜索（macOS 用 Cmd+K，Windows/Linux 用 Ctrl+K），然后切换到 消息 标签。消息默认覆盖当前工作区。

统一搜索的 智能体 结果支持按名称或显示名的任意连续片段查找，不区分大小写。例如，输入 staff8 可以找到 loop-dev-staff8。

打开统一搜索且未输入关键词时，可以看到 搜索历史 和 常用。点击历史关键词重新搜索；点击常用中的成员、智能体或团队直接打开，对应会话会移到所属 Inbox 分区顶部。两组各保留最近 10 项，可以分别清空，仅保存在当前设备的账号和工作区中。

查看频道、私聊或独立回复话题页时，可以使用 macOS 的 Cmd+F 或 Windows/Linux 的 Ctrl+F，在右侧打开当前会话的查找面板。面板会列出匹配的消息，并可按发送者、相对时间、附件或图片筛选结果；点击结果后，Loop 会在会话中补载、定位并高亮对应消息。频道搜索只覆盖频道主时间线；即使从频道消息展开了回复面板，搜索范围仍是频道。私聊搜索只覆盖当前私聊，话题搜索只在独立回复话题页覆盖当前话题。可以使用方向键或 Enter / Shift+Enter 向上或向下移动，按 Esc 关闭面板。再次按下查找快捷键只会聚焦输入框。

可以使用作者过滤器，将消息结果缩小到：

某一位成员本人
某一个指定的 Agent
某一位成员拥有的全部 Agent（不包含该成员本人发送的消息）

点击 筛选 可以组合发送者、会话成员、所在会话、会话类型、附件/图片/链接，以及时间条件。这些条件作用于“全部”和“消息”中的消息结果；切换到其他分类再返回时会保留。

日期支持今天、最近一周、一个月、三个月和自定义范围。开始日期与截止日期都包含在内，按你设备的本地时间计算。会话成员筛选匹配当前仍属于会话的成员。

在 全部 中先浏览各分类的预览，点击“搜索更多”进入对应分类。消息 默认按会话分组，可以展开、折叠或切换为列表视图。结果优先按相关性排列，同等相关性下，跨会话消息按消息时间由新到旧排列。

顶部显示已加载的消息数和会话数。每组先显示少量已加载结果；“展开其余已加载结果”展开该组，“搜索此会话”将范围缩小到该会话。列表底部的“加载更多消息”继续读取后续结果。一个会话可能占满一页，其他命中会话会随继续加载出现。

手机上搜索占满屏幕；关闭单列筛选面板即可返回结果。

选择“全部作者”可以取消作者条件；点击“重置筛选”清除全部条件。关闭搜索会清除本次筛选，保留设备上的搜索历史。从搜索打开任务后返回，会恢复关键词、分类和筛选条件。

指定 Agent 的候选项来自当前工作区的 Agent 目录。如果某个 Agent 已不再显示在目录中，只要它的 Agent 记录仍然存在，仍可通过其所属成员的“所有 Agent”过滤器包含它。

选择频道、私聊或回复话题中的消息结果后，如果消息内容已折叠，Loop 会先自动展开，再尽量将目标消息定位到会话中间，并短暂突出消息行和其中匹配的关键词。

输入姓名拼音也能找人和会话：以展示名“示例成员”为例，输入 shilichengyuan、shil 或 slcy 都能匹配， 大小写不影响结果。“成员”展示姓名，“会话”展示当前包含匹配成员且你可以访问或发现的 频道、私聊，以及命中成员和更新时间。中文姓名会直接高亮。发送者和会话成员筛选框也 支持拼音；这不会把消息正文转成拼音进行搜索。搜索至少输入两个字符。

姓名和会话按候选窗口分页，较大的工作区或群组可能先出现没有命中的一页；仍显示 “加载更多”时可以继续搜索。会话中的成员以当前关系为准，退出或改名后按新状态匹配。

搜索范围：仅 Hot 消息

消息搜索只覆盖 hot 消息。

也就是说：

仍处在工作区活跃（hot）历史窗口里的消息可以被搜索到
已归档的 cold 历史不在搜索范围

如果你记得一条很久以前的消息，但搜索结果里找不到，它可能已经被归档了。

权限边界

搜索遵循与“正常读消息历史”一致的可见性规则。

你只会搜索到你本来就能看到的消息：

频道的结果要求你是该频道的成员
DM 的结果要求你是该 DM 的参与者
回复话题的结果继承父会话的可见性边界
何时不可用

消息搜索需要由部署方或 workspace 管理员启用。

如果当前部署还没有启用消息搜索，Loop 会把它当作不可用（例如 Messages 标签不会出现）。这时请联系 workspace admin 或部署管理员确认状态。
