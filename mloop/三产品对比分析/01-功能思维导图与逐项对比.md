# 功能思维导图与逐项对比

研究日期：2026-11-08。完整交互版见同名 HTML。

核心区别：Loop 围绕协作会话，Multica 围绕事项与执行，MobileWork 围绕个人工作空间与任务对话。未核验不代表不存在。

## 对象关系

### 平凯 Loop
- 组织 / 工作区 → 频道 1:N：权限与归属
- 频道 → DM / 回复话题：会话上下文
- 频道 → 任务 1:N：任务恰属一频道
- 任务 → 讨论 / 进展 / 产物：持续工作记录
- Agent Team → Agent 1:N：创建者个人所有
- Machine + runtime → Agent 执行：机器位置≠身份

### Multica
- 工作区 → 项目 / 事项：项目可选
- 项目 → 事项 1:N：事项至多一个项目
- 事项 → 评论 / 子事项：子状态独立
- 事项 → Run 1:N：执行结果≠业务完成
- Squad → 人 + Agent：leader 必须 Agent
- Runtime → Agent / Run：Access 与本机权限分开

### MobileWork
- 账号 → 本地 / 远程工作空间：目录或连接
- 工作空间 → 任务 Session 1:N：本地新任务建子目录
- Session → 消息 / 回合 1:N：持续对话
- 主专家 → 子代理 / 专家团：执行拆分
- 回合 / 子会话 → 工具 / 浏览器 / 文件：引擎实际执行
- 自动化 → 独立 Session：每次触发新对话
