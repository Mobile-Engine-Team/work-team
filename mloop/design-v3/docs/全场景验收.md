# MobileWork 第三版 · 全场景验收

范围是第三版当前导航和从业务对象可达的二级操作，包含空工作区从零搭建、模拟工作区正常及异常路径。不以旧版验收 JSON 或截图作为本轮通过证据。真实服务验收和未逐一实测的分支单列。

**本轮结果：7/7 套通过**（6 条预配策略单元测试 + 6 套浏览器脚本）。覆盖当前产品模块的主要流程、空态和代表性失败分支；未逐项跑完的组合及正式服务发布条件见第 4 节。

## 1. 环境与复跑

- 本轮环境：2026-11-27，macOS 27.0，Node 26.12.0，Playwright 1.58.2，Chromium 141.0.7390.37。验收对象为 `node build.mjs` 重建后的第三版静态包。
- 使用 `node serve.mjs` 并打开 `http://127.0.0.1:8086/`。不依赖后端、真实账号、模型或 API 密钥。
- 自动验收使用 Chromium + Playwright，**仅验收工具**需要这两项。已有工具的环境下执行 `node tests/run.mjs`；跨目录安装 Playwright 时设置 `NODE_PATH` 为其 `node_modules`，使用已有 Chromium 可设 `CHROMIUM_PATH` 为可执行文件。脚本默认自己起 8096 静态站点，可设 `MLOOP_TEST_PORT` 或用 `MLOOP_URL` 指向已经启动的本地站点。
- 每个浏览器脚本用全新浏览器上下文；UI 环节不共享个人站点数据。`project-*` 选定分支使用专用 fixture，`local-acceptance` 大部分由菜单实建，仅过期链接用改时间构造；`lifecycle-acceptance` 使用 Playwright 虚拟时钟推进建议等待、其余走实际 UI。通过以退出码与脚本断言为准。
- 桌面主流程 1440×900，另外检查约 880 宽的蓝图操作及 390 宽的任务临时会话、文件列表。并非覆盖所有分辨率、系统、浏览器和无障碍设备。

## 2. 业务验收矩阵

证据简称：`L` = `tests/local-acceptance.cjs`；`C` = `tests/lifecycle-acceptance.cjs`；`P` = `tests/project-regression.cjs`；`S` = `tests/project-status-regression.cjs`；`F` = `_src/verify-fresh-workspace.cjs`；`I` = `_src/verify-conversation-interactions.cjs`；`U` = `_src/composer-capabilities.test.mjs`。下表中的预期是可复测的业务结果，不是生产能力承诺。第 4 节列出没有实测的边界。

| 编号 / 场景 | 前置与操作 | 预期 / 实测依据 |
|---|---|---|
| W01 空工作区 | 创建团队，进入全部项目/任务；创建时不点演示 | 无项目/业务任务，创建入口可用，内置 Work 不算自建代理。`L/F` |
| W02 演示团队隔离 | 连续点「新建演示工作区」两次，再回第一份 | 团队 ID 不同、原数据不丢；V1、未发布草案与空项目可同时进入。`L` |
| W03 空间权限、身份和导航 | 所有者、普通成员分别看空间；三个标签页分别选择身份并刷新 | 成员只读；身份同标签页可恢复、不改变其他标签页；协作空间、智能体、小队平级。`L/F/P` |
| W04 指定邮箱入队 | 所有者添加两位测试邮箱；用对应标签页打开及接受 | 非本人不可接受，接受后管理页同步，两份独立身份；不发实际邮件。`F` |
| W05 通用邀请 | 创建、复制、接受、再接受；停用/启用、删除；构造过期链接 | 同一成员不重复加入；停用、过期和删除后无效。`L` |
| D01 首页输入与分流 | 试可点推荐/回车、普通问题、知识入口、任务创建 | 推荐只填草稿，空输入不发；入口卡只打开操作，创建需确认；消息按意图分流。`F/I` |
| D02 Work 成败与产物 | 演示空间发普通请求加 `【模拟失败】`，再去标记发送；刷新 | 失败没有新文件，成功至少一份可下载产物，历史消息恢复；不是实际模型。`L` |
| D03 多人会话 | 用同一地址的不同标签页做人对人私聊、三身份群聊、@Work | 可见成员能读新消息；第三身份不能看到私聊；群可关联项目，@Work 摘要来自可见聊天记录。`F/I` |
| D04 任务来源与临时会话 | 由群聊创建任务、从来源回群；由私聊创建后换非参与者；打开 task 内 Work 临时栏 | 任务指向创建来源；非参与者不显示私聊名及链接；临时会话不入最近，不修改源对话，关闭/刷新清空。`F/I` |
| D05 输入能力与预配 | 分别从 Work、智能体、小队入口进入；检查发送策略 | 会话没有模型/模式切换；结构化 payload 使用目标预配，纯人类消息不携带 AI 执行选项。`F/U` |
| Q01 全局搜索与通知 | 搜不存在的词/任务/私聊；换非参与者；点单条和全部已读并刷新 | 空结果、点任务直达、排除私聊；浏览器保存读状态，全部保留历史。`C` |
| Q02 主动建议 | 演示团队待推进项目；前台推进测试时间、展开原因、延后一小时、点击一起看一下 | 解释有事实，延后窗口不自动弹；到期候选重新按规则评估；按钮新建查询会话并发送，不改任务。`C` |
| Q03 看板视图 | 查询进展、追问筛选、固定结果、刷新版本、再取消；打开旧固定地址 | 实时查询读本地任务；刷新新版本；取消仅移除固定，源会话还在，旧快捷地址给空态。`F/C` |
| Q04 我的文件 | 从工作区看同名不同来源附件，类型/搜索/空结果、下载、来源；切非参与者 | 有内容才下载，样例原字节可读，私聊附件不露出，云盘明确未接入；390 宽无横向溢出。`L` |
| P01 项目入口与设置 | 搜索/新建、标日期、进入三个页签；把另一标签页的会话关联项目，再改名、删除 | 列表含空态，仅总览/施工蓝图/任务，无讨论/资源；会话归属跟随改名；删除解除关联并保留任务和会话。`P` |
| P02 画布编辑 | 加已有、加拟新增、连依赖、拖节点、框选、缩放、撤销/重做并刷新 | 布局重新打开仍在；发布前不产真实拟新增任务；窄屏能用画布操作。`P` |
| P03 AI 草案与发布 | 预览并采纳样例建议、查看变更、发布、打开历史 | 采纳只改草案；发布才创建待规划任务；历史作为只读版本，可回当前正式版。`P` |
| P04 任务页及推进状态 | 展开内部任务；分别检查前置未完、无负责人、阻塞、进行中、可推进、已记录 | 仅有资格项可选；只提示直接下游；记录通知或执行请求后不重复，不自动实际执行。`P/S` |
| T01 全部任务 / 我的任务 | 多选项目/状态/负责人，检查六维入口，标题升降序、负责人排序、无匹配清除；回我的任务 | 原我的任务操作保留；全部任务无分类下拉和左下新建，表格只有原右上新建入口；各列可做主要排序键，不是复合排序。`P` |
| T02 任务创建及状态 | 手动新建并指定项目、从 Work 确认任务、切看板并修改状态；读旧层级任务 | 任务落全局对象，独立创建无来源；任务状态现场同步；删旧上级不级联删除。`P/F` |
| T03 任务评论及引用 | 发送、改、点赞；别人检查操作菜单并回复；删原评论；加入无效/有效链接，刷新后检查并确认移除 | 空发送禁用，自评可编辑/删除，其他人只有复制/回复等；回复不被级联删除，HTTP(S) 引用重载后仍呈现为可点击链接，确认移除后消失。`C` |
| T04 任务唤醒及运行 | 填过去/未来日期；暂停、恢复、刷新、删除；分别对真人/智能体负责人点运行 | 过去时间拒绝；仅保存本地提醒配置；只允许匹配智能体/小队创建「待运行」回执，真人禁用。`C` |
| A01 智能体建立和调用 | 创建向导、打开详情、对话与 Work 常规指派 | 可从空空间新建、预配对象可调用，通过真实任务表单指派。`F/U` |
| A02 智能体生命周期 | 搜无结果、清空、筛离线、快编描述、指定成员留空再保存、归档/恢复 | 空成员拒绝；描述/访问选择刷新后保留；归档可在已归档中恢复。`C` |
| A03 小队生命周期 | 创建并选队长、加成员、用小队开聊；修改描述与角色后刷新、再归档 | 混合队伍可对话；编辑持久化；归档从可用列表移除，当前不提供恢复。`F/C` |
| R01 设置数据及帮助 | 深色/系统、字号和重载；改指令、切身份、改记忆、增删模型样例、复制版本、开手册 | 实际字号只作用聊天；指令按身份；无密钥或真实模型；手册为本地内容。`L` |
| R02 运行时 | 改守护进程偏好；Qoder 验证非法和合法假值；远程选择「模拟连接」 | 偏好可恢复；假 token 不写盘；仅创建本地运行时对象、没有真实网络连接。`L` |
| R03 无后端与退役导航 | 阻断外部请求跑本地验收；打开八条退役链接 | 该验收链无本地 4xx、外部请求及页面 JS 异常；旧链接进入相同团队首页。`L` |

## 3. 验收中发现并修复的问题

| 问题 | 修复及复测 |
|---|---|
| 任务填写关联链接后没有回看入口 | 详情显示链接，先验证协议再保存；确认移除只解除引用。见 T03。 |
| 主动建议与任务临时侧聊底部操作重叠 | 侧聊打开时不触发新的主动提醒，并隐藏已显示的提醒。见 D04、Q02。 |
| 已关联的会话在改项目名后仍指回旧名字 | 改名同步当前会话及未确认建议的归属，删项目只解除关联；不会删除会话或任务。见 P01。 |

## 4. 未逐项覆盖与发布门槛

- **原型可操作，但尚未在本轮逐个交互回归：**团队头像文件上传、成员提权/降权/移出、定向邀请的撤销与发送人回执、会话内双模式搜索全部快捷键、全部任务所有日期/标签/优先级筛选组合及列排序、CSV/批量操作/自定义看板列与拖拽、任务表单所有起草入口及附件容量故障、蓝图跨标签并发发布和每种字段冲突、智能体环境变量/参数各异常输入、归档对所有旧指派的迁移、小队更换队长和移除成员、运行时所有平台/自定义参数与停用流程、设置每个偏好和辅助键盘路径。按手册步骤复测；不把这些直接标为实测通过。
- **明确不做或仅 Mock：**真实认证、跨设备/浏览器数据、多租户隔离、邮件/系统推送、离开网页后的调度、真实模型流式输出/工具调用、云盘、Shell/仓库连接、计量与审计、操作系统功能。项目推进仅记回执，任务运行仅记「待运行」。勿用开发者工具中可读的浏览器存储作为权限安全边界。
- **生产发布还需要**两设备真实多人、服务端拒绝越权和附件 ACL、事务回滚/重复请求/冲突回读、后台派发失败恢复、时区与夏令时、日志与费用对账、无障碍与兼容性验收。具体对象和写入边界见《使用与实现手册》第 9 节。
