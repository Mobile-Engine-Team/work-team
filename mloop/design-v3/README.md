# MobileWork 多页静态设计稿

## 当前版：无后端本地启动

```sh
node serve.mjs
```

在本目录执行，打开 `http://127.0.0.1:8086/`；端口冲突时用 `node serve.mjs 8087`。预构建资源可直接运行，不需要安装依赖、后端、账号或 Key。请用 HTTP 打开，不要双击 HTML。左上团队菜单的「新建演示工作区」填入可操作样例；「创建团队」则保留空状态。数据仅保存在当前浏览器站点；模型与真实运行环境未接入。

- [使用与实现手册](docs/使用与实现手册.md)：各入口、操作、副作用、错误边界和后端参考。
- [全场景验收](docs/全场景验收.md)：验收矩阵、复跑方法、覆盖与未覆盖的分支。
- [新团队协作验收手册](新团队协作验收手册.md)：从零建立团队的多标签页实操。

开发者验收入口：`node tests/run.mjs`（仅测试需要 Playwright + Chromium）。修改源码后 `node build.mjs` 重建；构建借用当前工作区的 Work 依赖和同机 Multica 的 Tiptap，运行预构建包不需要这些依赖。

下文仅保留历史记录，若与当前手册不一致，以当前手册为准。旧定时任务、专家、市场与智能体 MCP/Skill 配置不是第三版当前入口。

## 2026-11-16：会话内的 A2UI 渐进查询卡片

首页增加三个可直接发起的查询：成员最近进展、项目进度概览、阻塞与逾期事项。输入“查询一下当前肖叶茂最近的进展”也会触发卡片。读取当前团队未归档的本地任务，成员按负责人匹配（兼容 xym），项目按所属项目匹配，风险按阻塞或逾期且未结束的任务筛选。默认成员查询为近 7 天；项目概览和风险清单默认全部记录。未记录日期的任务只在“全部记录”显示。

卡片依次展示检索状态、骨架、标题、摘要、状态指标、事项明细和来源操作，约 5.5 秒完成；支持近 7 / 30 天 / 全部记录、状态筛选、展开明细、事项详情和原始任务链接。支持停止、重新查询、后续提问、刷新恢复、窄窗口与减少动态效果。生成时保留摘要可见位置，不强制跳到长卡片底部。

参考 copilotkit-a2ui 的 catalog / surface / data model / action 分层，在现有静态稿中实现受限的本地组件目录及 createSurface、updateDataModel、updateComponents 分片渲染。当前不是 CopilotKit runtime 或真实模型的流式连接；查询规则和流式分片由本地实现。卡片保存查询时的数据快照，点击“重新查询”读取最新任务。真实任务只读，不会创建或改写任务。

工作区没有匹配记录时，肖叶茂的进展、空项目和空工作区风险查询可展示独立的示例卡片；标题区域明确标记“示例数据”，展开数据说明可查看原因。其他未匹配成员显示空状态。示例不写入工作区，也不提供虚假的任务链接。

源码：`_src/a2ui-query.ts`、`_src/a2ui-progress.tsx`、`_src/a2ui-progress.css`；会话接入在 `collaboration-store.ts` 与 `collaboration.tsx`。验证见 `a2ui-query-verification.json`。

### 统一会话与前端主动提醒（2026-11-16）

产品仅保留会话、任务两个工作实体。Work、智能体私聊、群聊和小队入口统一解析为 `index.html?conversation=...`，共用 Collaboration、WorkComposer、会话设置、消息搜索、附件、任务草稿和 A2UI 卡片。旧智能体及群聊记录按稳定 ID 迁移一次，原始数据保留；刷新不会重复迁入。私聊默认由对应智能体回应，小队默认由队长回应，显式 @ 时按提及对象参与。

「多想一步」基于当前本地任务状态、本人负责事项、历史讨论和查询习惯排序。后台定期检查，用户连续输入、页面不可见和弹窗操作时暂缓。自动提醒间隔至少三分钟，同一信号一天内不重复；可收起、展开，或暂停一小时。收起保留当前事项，手动展开不会随机编造新提醒。风险解除后移除过期建议。点击「一起看一下」开启新会话，以自然语言查询当前项目，并逐步生成摘要、指标、图表、明细和操作。

本版本的查询、卡片、任务创建、附件保存、历史恢复与提醒在前端闭环；本地规则生成回复，不调用远程大模型或业务后端。同源浏览器页面共享保存的数据，不代表跨设备同步或已接入外部邮箱、联网调研。

### Work 软件升级全流程案例（2026-11-16）

打开 `work-upgrade-demo.html`，点击「开始一轮新演示」。页面左下角有可收起的演示路线，依次创建邀请、接受邀请、配置研究助手、与 Work 讨论、与同事确认目标、从消息卡片创建四项任务、在任务下协作、切换领导查询，再观察兼容阻塞引发的自动提醒，最后跟进并复查。每轮独立创建空间，支持刷新续演。操作脚本见 `demo/work-upgrade-walkthrough.md`。角色对话与事件为前端演示场景，所有任务、关联、评论、卡片与提醒使用共享本地数据，不发送真实邮件或调用远程模型。

### 邀请通知、入群摘要、双模式检索与固定看板（2026-11-17）

团队邮箱邀请和会话成员邀请均进入右上角通知中心。接收者点击通知可接受邀请，接受后邀请人收到回执；团队邀请可通过原有邀请链接打开。接受时重新校验当前身份与邀请状态，已撤销邀请无法接受，重复接受不重复添加成员。通知已读状态仍按团队与成员保存，同源页面通过存储事件同步。

新成员入群后，会话增加一条由「系统通知」发送的历史摘要，按项目背景、明确确认的讨论记录、关联未完成任务整理。摘要标记「仅你可见」，通过 `visibleTo` 限定接收成员；其他成员的消息流、通知、消息搜索、会话预览和助手执行上下文均排除这条私有消息。摘要不重复生成，也不会复制其他成员的私有摘要。这里是前端展示隔离；正式服务仍须实施服务端访问控制。

左侧搜索入口或 ⌘/Ctrl K 打开全局关键词搜索，覆盖会话、可见聊天记录、团队成员、智能体、小队、任务和项目。会话右上角搜索打开右侧面板，支持「快搜 / 智能」切换并保留同一个问题；智能模式直接在右侧打开现有 Work 会话，复用 Collaboration、WorkComposer、WorkExecution 与普通消息流，输入框固定在底部。切换智能时自动发送已输入的问题；搜索旁的聊天按钮直接打开临时 Work。对话仅在内存中存在，关闭面板即清除，重新打开为空白，且不出现在左侧会话列表。原会话的可见历史与关联任务作为上下文；查找任务或回顾讨论时，回复以普通 Work 消息呈现并附来源链接。沿用项目当前的本地 Work 执行流程，尚未连接远程模型。

任务详情上方内容独立滚动，下方评论/回复框固定可见；会话原有输入框继续固定。生成的进展卡片在「重新查询」右侧增加「固定看板」，保存当前查询条件和时间范围。左侧「看板视图」按团队与身份保存，默认展示三项，支持显示更多和取消固定。固定看板不显示聊天生成操作，右上角提供刷新数据图标。打开看板无需发送消息，读取最新任务，并随同源任务数据变更更新；没有匹配数据时显示空状态，不用示例任务替代。
